# Sightcraft design

Approved brief: the conversation's screenshot-to-design giveaway plan, with the user's chosen spelling Sightcraft and explicit instruction to create it.

Audience: Thai-speaking people using a vision-capable AI to build websites.
Deliverable: a local Git repository and ZIP containing an instruction-only skill, Thai quick start, reusable output templates and one original end-to-end example.

Input: one or more screenshots plus the user's website purpose and content. Output: DESIGN.md with observed, estimated and proposed information; BUILD-PROMPT.md that preserves that distinction and follows the target project's existing stack (plain HTML/CSS for a new standalone example).

Scope: no API key, service integration, automatic URL fetcher, deployment or publication. The user's selected AI may have its own charges. Manual chat attachment is a documented route, not a claim of native installation on every provider.

Example direction: an editorial design studio with warm paper, near-black type, acid-lime accents, a typographic poster and ruled project listings. Original reference is FORM / FIELD; adapted Thai business is Baan Form. Reference and adaptation use native anchors and details controls, without network resources or JavaScript. Target viewports: 1440x1000 and 390x844; also check 320px and 200% text. A 1440x540 capture is the partial-reference test. Only the adaptation's mobile treatment is a proposal from the desktop reference.

Acceptance: open the extracted ZIP's comparison page, see both images, follow working links, use keyboard controls, verify no horizontal overflow, and report limits honestly. A small Python standard-library checker verifies required artifacts and local document links, with regression tests. Source examples and screenshots are MIT, authored here. No reference from another brand is bundled.
