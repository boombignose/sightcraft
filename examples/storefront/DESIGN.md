# DESIGN — Orbit Store พร้อม motion และตะกร้า

หน้าร้านสมมติภาษาไทย ใช้โครงที่ทดสอบจากภาพส่วนบนของ Apple Store ไทย: nav เตี้ย → hero แบ่งซ้ายขวาบนจอใหญ่/เรียงลงบนมือถือ → แถวหมวด → การ์ดแนวนอน ภาพ Apple ไม่ได้อยู่ในชุดแจกนี้ ส่วนรูป SVG และโค้ด Orbit เป็นงานตัวอย่างที่สร้างขึ้นเอง

## สิ่งที่ยึดจากภาพและค่าประมาณ

พื้นเทาอ่อน การ์ดขาวมุมมน ภาพสินค้าเด่นและใบถัดไปโผล่ในแนวนอน เห็นจากภาพที่ใช้ประเมินก่อนหน้านี้ ค่าสีเริ่มต้น #f5f5f7 / #1d1d1f / #0066cc และฟอนต์ระบบเป็นค่าประมาณ/ทางเลือกของ Orbit ไม่ใช่ค่าที่วัดหรือยืนยันฟอนต์ต้นฉบับ

การ์ดกว้างราว 400px บนจอใหญ่และ 310px ที่ 390px ลดลงเป็น viewport ลบ 44px บนจอแคบ ภาพเป็น illustration จึงต่างจากภาพสินค้าจริงของ Apple ต้นฉบับส่วนล่าง สถานะ hover และ animation ยังยืนยันจากภาพนิ่งไม่ได้

## Motion — เสนอเพิ่มทั้งหมด

| Trigger | Effect | เวลา / easing | Reduced motion |
| --- | --- | --- | --- |
| เปิดหน้า | Hero/หมวด/การ์ด opacity 0→1, translateY 12→0 | 420ms, cubic-bezier(.2,.8,.2,1) | แสดงทันที |
| Hover ที่การ์ด | ยก 4px, ภาพ scale 1.025 | 240ms, easing เดียวกัน | ไม่ขยับ |
| เปิดตะกร้า | Panel opacity 0→1, translateX 24→0 | 240ms, easing เดียวกัน | เปิดทันที |
| เพิ่มสินค้า | Badge scale 1→1.22→1 | 160ms ease-out | เปลี่ยนตัวเลขทันที |

CSS เป็น progressive enhancement: ถ้าไม่มี motion เนื้อหายังอยู่ครบ ถ้าปิด JavaScript ยังอ่านสินค้า/เปิด native details ได้ ปุ่มตะกร้าปิดใช้และมี noscript อธิบาย

## Behavior contract — เสนอเพิ่มตามโจทย์ผู้ใช้

| Control | ผลจริงและข้อมูล | กรณีว่าง/ผิดพลาด | ตรวจอย่างไร |
| --- | --- | --- | --- |
| หมวด/เมนู | Fragment ไปยังรายการ 6 หมวด; เมนูมือถือเปิด/ปิดและ Escape ได้ | 2 หมวดไม่มีสินค้าตัวอย่าง แสดงข้อความว่าง | กดทุกหมวดและไล่คีย์บอร์ด |
| เพิ่มสินค้า | อ่าน ID/ชื่อ/ราคาจาก catalog ใน HTML; เพิ่มจำนวนสูงสุด 99 | เมื่อเต็ม แสดงข้อความและไม่เพิ่มเกิน | เพิ่ม Phone 2 + Buds 1 ต้องได้ 63,700 |
| ตะกร้า | Native dialog ชื่อชัด เพิ่ม/ลด/นำออก/ล้าง คำนวณยอดใหม่ | ว่างแล้วปุ่มดาวน์โหลด/ล้างปิดใช้ | เพิ่ม→ปรับจำนวน→นำออก→ล้าง |
| จำตะกร้า | localStorage เก็บ version/IDs/จำนวน ไม่มีข้อมูลบุคคล/ราคาที่เชื่อถือจาก storage | ข้อมูลเสียแจ้งเริ่มใหม่; บันทึกไม่ได้ยังทำงานใน session | Reload, corrupt JSON, denied storage |
| ดาวน์โหลด | บันทึกข้อความสรุปชื่อ/จำนวน/ยอดลงเครื่อง | ตะกร้าว่างดาวน์โหลดไม่ได้; ไม่อ้างส่งออเดอร์ | เปิดไฟล์ที่ดาวน์โหลด ตรวจ 3 ชิ้น 63,700 |

## เกณฑ์ตรวจและสิ่งที่ยังไม่ทราบ

ตรวจ viewport 1440/390/320 และช่วง 767/768, text 200%, modal focus/Escape, normal/reduced motion และ local file smoke ภาพต้องเปิดตรวจจริง ไม่รับรอง browser ที่ไม่ได้ตรวจ และ file:// ไม่รับรองการจำข้อมูลข้ามครั้ง ไม่มี stock/order/payment backend
