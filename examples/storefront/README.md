# Orbit Store — ตัวอย่าง motion และตะกร้าที่ใช้งานได้

เปิด [index.html](index.html) แล้วเลื่อนลงแถวสินค้า กด **เพิ่มลงตะกร้า** จากนั้นเปิดตะกร้ามุมขวาบน ปรับจำนวน นำสินค้าออก หรือล้างตะกร้า และกด **บันทึกสรุป (.txt)** เพื่อดาวน์โหลดรายการลงเครื่อง

ตัวอย่างตรวจง่าย: Orbit Phone Pro 2 ชิ้น + Orbit Buds 1 ชุด = 3 ชิ้น รวม **฿63,700** ดู [ไฟล์สรุปจากการทดสอบจริง](../../docs/evidence/storefront/sample-summary.txt)

## เปิดแบบจำตะกร้าได้หลัง reload

จากโฟลเดอร์ repo ใช้:

```sh
python3 -m http.server 8768 --bind 127.0.0.1
```

แล้วเปิด [Orbit Store ในเครื่อง](http://127.0.0.1:8768/examples/storefront/) ใช้ address และ port เดิมเมื่อต้องการตะกร้าเดิม

เปิดไฟล์โดยตรงก็ใช้สินค้าและตะกร้าได้ใน Chrome ที่ตรวจ แต่การจำข้อมูลของ file:// ขึ้นกับ browser จึงไม่รับรอง persistence ในโหมดนี้ ตาม [เอกสาร localStorage ของ MDN](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage) ถ้า browser ไม่ให้บันทึก เว็บยังใช้ตะกร้าในรอบนั้นได้และแสดงข้อความอธิบาย

## Motion ที่มี

- หัวเรื่อง/หมวด/การ์ดค่อย ๆ ปรากฏด้วย opacity และ translate ระยะสั้น 420ms
- Hover บนอุปกรณ์ที่รองรับ: การ์ดยกขึ้น 4px และภาพสินค้าโตเล็กน้อย
- เปิดตะกร้าเป็น panel 240ms; จำนวนสินค้าเด้งเบา ๆ หลังเพิ่ม
- เมื่อเปิด reduced motion จะปิด animation/transition และ smooth scrolling; controls ยังทำงาน

ทั้งหมดเป็น animation ที่ออกแบบเพิ่ม ไม่ใช่พฤติกรรมที่ถอดยืนยันจากภาพนิ่ง Apple

## ข้อมูลและขอบเขต

ราคาอยู่ใน `data-price` ของการ์ด HTML หน่วยบาทเป็นจำนวนเต็ม จำนวนต่อสินค้า 1–99 ตะกร้าจำเฉพาะ ID/จำนวน ไม่เชื่อราคาที่อาจมีในข้อมูลบันทึก ไม่เก็บชื่อ ที่อยู่ หรือรายละเอียดส่วนตัว

ภาพสินค้าเป็น SVG ที่สร้างขึ้นสำหรับตัวอย่างนี้ ชื่อและราคาสมมติ ไม่มีระบบส่งออเดอร์หรือชำระเงิน ข้อความในไฟล์สรุประบุสถานะนี้ชัดเจน

## ทดสอบ

จากโฟลเดอร์ repo ใช้ `node --test tests/cart.test.cjs` (Node 22 สำหรับการพัฒนาเท่านั้น) เพื่อเช็กจำนวน ยอดรวม ข้อมูลเสีย และสรุปรายการ Browser ที่เปิดตัวอย่างไม่ต้องติดตั้ง Node

เปิด [self-check.js](self-check.js) คัดลอกลง browser console แล้วรัน `await orbitSelfCheck()` เพื่อตรวจเมนู ลูกศร ขอบแถวและคอนทราสต์พื้นฐาน สำหรับตะกร้า ให้ทดลองเพิ่ม → ปรับจำนวน → reload → ดาวน์โหลด → นำออก/ล้าง ตามรายงาน
