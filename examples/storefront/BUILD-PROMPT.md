# BUILD-PROMPT — Orbit Store ที่ใช้งานได้ในเครื่อง

สร้างหน้าร้าน Orbit ตาม DESIGN.md ที่แนบ ใช้โครงเดิม/ภาพ SVG เดิม และ HTML/CSS/JavaScript ไม่มี dependencies หรือ external requests รักษาข้อความและราคาตัวอย่าง ไม่เพิ่มสเปกหรือข้อเสนอธุรกิจขึ้นมาเอง

เพิ่ม motion ตามตาราง trigger/effect/duration ใน DESIGN.md เป็นข้อเสนอเพิ่มจากภาพนิ่ง ใช้ opacity/transform; เนื้อหามองเห็นได้เมื่อ motion/JS ใช้ไม่ได้ รองรับ prefers-reduced-motion ทั้ง CSS และการเลื่อนจากปุ่ม

ทำปุ่มเพิ่มสินค้าทั้งสี่ ตะกร้าเป็น native dialog ที่มีชื่อ คีย์บอร์ดใช้ได้ ปิดด้วย Escape แล้วคืน focus เพิ่ม/ลดจำนวน 1–99 นำออกและล้างได้ ยอดรวมใช้ราคาจาก catalog จำนวนเต็มบาท เก็บใน localStorage เฉพาะ IDs/จำนวน ไม่รับราคาจาก saved data ข้อมูลเสียหรือ storage ถูกบล็อกต้องมีข้อความอธิบายและตะกร้าในรอบนั้นยังทำงาน

ปุ่มบันทึกสรุปต้องดาวน์โหลด .txt จริง มีชื่อสินค้า จำนวน ยอดต่อรายการและยอดรวม ระบุว่าเป็นสรุปในเครื่อง ยังไม่ใช่คำสั่งซื้อและไม่มีการรับชำระเงินจริง ไม่เก็บข้อมูลบุคคล ไม่เพิ่ม backend หรือ deploy

ทดสอบ Phone 2 เครื่อง + Buds 1 ชุด = 63,700 บาท ปรับจำนวนแล้วตรวจยอด Reload แล้วต้องคืนข้อมูลเมื่อเปิดบน localhost address/port เดิม ดาวน์โหลดแล้วเปิดไฟล์ตรวจข้อความ นำออกและล้างแล้วปุ่มดาวน์โหลดต้องปิดใช้ ทดลอง invalid saved JSON, unknown ID/จำนวนผิด และ denied storage

เปิดตรวจจริงที่ 1440/390/320 และขอบ breakpoint 767/768 ตรวจข้อความ 200%, focus ใน modal, สีข้อความเล็ก, normal motion และ reduced motion ตรวจ file:// ว่าอ่านไฟล์ local ได้และแสดงข้อจำกัดการจำตะกร้า รายงานเฉพาะสิ่งที่ทดสอบแล้ว
