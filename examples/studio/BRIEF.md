# โจทย์ตัวอย่าง — บ้านฟอร์ม

สร้างหน้าแนะนำสตูดิโอออกแบบสมมติ “บ้านฟอร์ม / BAAN FORM” ภาษาไทย จากภาพ FORM / FIELD ในชุดนี้ อยากได้ความรู้สึกอบอุ่น มีระบบ และกล้าใช้ตัวอักษรใหญ่ รักษา hero สองคอลัมน์ ภาพโปสเตอร์เรขาคณิต โทนกระดาษ และเส้นคั่นบาง

- เนื้อหา: “งานที่ใช่ ในแบบคุณ” / “เราเปลี่ยนไอเดียของคุณให้เป็นแบรนด์และเว็บไซต์ ที่ชัดเจน ใช้ง่าย และมีบุคลิกของตัวเอง”
- CTA: “ดูงานของเรา” ไปยังส่วนผลงาน; เมนูผลงาน / รู้จักเรา / คุยกัน
- ผลงานสมมติสองชิ้น: “พอดี — แบรนด์กาแฟในจังหวะของคุณ” และ “วันว่าง — พื้นที่ให้ชีวิตได้หายใจ” ต้องระบุว่าเป็น concept
- เนื้อหาเกี่ยวกับเรา: “คิดเป็นระบบ ออกแบบให้รู้สึก เราเชื่อว่างานที่ดีควรมีทั้งสองอย่าง”
- ปลายทางติดต่อเป็นส่วนอธิบายในหน้า ไม่มี backend หรืออีเมลจริง อย่าทำปุ่มส่งข้อความที่แสร้งว่าทำงาน
- เว็บใหม่ HTML/CSS เปิดไฟล์ได้โดยตรง ไม่ใช้ฟอนต์ออนไลน์ รูปภายนอก หรือ JavaScript
- เวอร์ชันมือถือเป็นข้อเสนอจากผู้สร้าง ตรวจที่ 390px และ 320px รวมข้อความขยาย 200%

ภาพต้นแบบและตัวอย่างสร้างโดยผู้จัดทำในเซสชันเดียวกัน ชื่อธุรกิจและผลงานทั้งหมดเป็นสมมติ ตัวอย่างนี้แสดงวิธีส่งต่องาน ไม่ใช่การวัดความแม่นยำแบบไม่เห็นต้นฉบับหรือการเปรียบเทียบโมเดล
