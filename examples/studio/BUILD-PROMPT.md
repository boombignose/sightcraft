แนบ [DESIGN.md](DESIGN.md), [BRIEF.md](BRIEF.md) และ [ภาพอ้างอิง](images/reference-desktop.png) แล้วคัดลอกพรอมป์ต์นี้ไปใช้

---

สร้างหน้าเว็บภาษาไทยของสตูดิโอสมมติ “บ้านฟอร์ม / BAAN FORM” ให้เปิด index.html ได้โดยตรง ใช้ HTML/CSS และองค์ประกอบ native ไม่มี JavaScript ฟอนต์ออนไลน์ หรือ assets ภายนอก งานจบที่ไฟล์ในเครื่อง

ใช้ DESIGN.md ที่แนบเป็นบรีฟ ค่าที่ระบุ “ประมาณ” เป็นค่าเริ่มต้นให้ปรับหลัง render ไม่ใช่ค่าที่พิสูจน์จากต้นฉบับ ถ้าทำในโปรเจกต์ที่มีอยู่แล้วให้ใช้ stack และองค์ประกอบเดิมแทนการเพิ่มอีกชุด

โครงหน้า: header แบรนด์ซ้าย เมนู “ผลงาน / รู้จักเรา / คุยกัน” ขวา → hero ซ้ายข้อความขวาโปสเตอร์ → strip งาน 4 กลุ่ม → ผลงาน 2 คอลัมน์ → about พร้อม details 2 รายการ → footer ติดต่อ

ข้อความ hero: “งานที่ใช่ / ในแบบคุณ.” คำบรรยาย “เราเปลี่ยนไอเดียของคุณให้เป็นแบรนด์และเว็บไซต์ ที่ชัดเจน ใช้ง่าย และมีบุคลิกของตัวเอง” CTA “ดูงานของเรา” ไป #work ข้อความเกี่ยวกับเรา “คิดเป็นระบบ ออกแบบให้รู้สึก เราเชื่อว่างานที่ดีควรมีทั้งสองอย่าง”

ผลงานสมมติ: “พอดี — แบรนด์กาแฟในจังหวะของคุณ” บนพื้นเขียวมะนาว และ “วันว่าง — พื้นที่ให้ชีวิตได้หายใจ” บนพื้นฟ้าเทาหม่น ระบุว่าเป็น CONCEPT ทั้งคู่ ไม่มีคำรับรองหรือจำนวนลูกค้า รูปประกอบใช้แผ่นตัวอักษรจากสองชื่อนี้

ทิศทาง: editorial studio กระดาษอุ่น #f1f0e7 หมึก #22291f ข้อความรอง #505b49 เส้นบาง #b9c0b1 แต้มมะนาว #d8f18b พื้นโปสเตอร์ #ddd1b9 อีกผลงาน #c7d8d4 ทั้งหมดเป็นค่าสีประมาณ Content max 1296px ขอบจอใหญ่ราว 5% hero สองคอลัมน์อัตรา 1.28:1 gap ราว 64px

หัวเรื่องใหญ่ 64–100px บนเดสก์ท็อป ปรับ line-height เป็น 1.25 เพื่อภาษาไทย ใช้ฟอนต์ระบบ Arial/Thonburi/Tahoma คู่ emphasis ที่ให้อารมณ์ serif italic โดยไม่สมมติชื่อฟอนต์ต้นฉบับ Body 16px line-height 1.75 Metadata 12px ปุ่ม pill สูงอย่างน้อย 50px

โปสเตอร์เป็นกระดาษทรายแนวตั้ง มีรูปเรขาคณิตแนวตั้ง 3 ชิ้น: แท่งดำ ทรงโค้งมะกอก และแท่งดำตัดทแยง มีวงกลมมะนาวด้านขวาบน วาดด้วย CSS และใส่ข้อความไทยของแบรนด์นี้ รูปทั้งหมดอยู่ในชุดตัวอย่าง MIT ที่สร้างเอง

มือถือ **เป็นข้อเสนอ**: ต่ำกว่า 760px เรียง hero/about เป็นคอลัมน์เดียว ข้อความก่อนรูป ขอบ 20px ผลงานเรียงลง เมนูขึ้นบรรทัดได้ ห้ามตัดคำไทย วรรณยุกต์ หรือซ่อนเนื้อหาเพื่อให้พอดี

ใส่ skip link, focus-visible และรายละเอียดที่อ่านด้วย screen reader ได้ รูปตกแต่งไม่ควรถูกอ่านซ้ำ ลิงก์ไปยัง section จริง details ต้องกด Enter/Space ได้ เคารพ reduced motion ส่วนติดต่อระบุว่ายังไม่มีบริการส่งข้อความเชื่อมต่อ

เปิดตรวจที่ 1440×1000, 390×844 และกว้าง 320px รวมข้อความ 200% ตรวจปุ่ม/ลิงก์/การพับคำถามจริง เทียบภาพหัวเรื่อง โปสเตอร์ ช่องว่างและลำดับสายตา บันทึกจุดต่างที่ยอมรับได้: ภาษาไทยทำให้ระยะบรรทัดเปลี่ยน ฟอนต์ระบบต่างตามเครื่อง และรูปโปสเตอร์อาจไม่ตรงทุกพิกเซล ส่งผลตรวจตามจริง ถ้าไม่ได้เปิดเว็บให้ระบุว่ายังไม่ตรวจภาพผลลัพธ์
