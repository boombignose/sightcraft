# DESIGN — บ้านฟอร์ม / BAAN FORM

## โจทย์และหลักฐาน

หน้าเว็บแนะนำสตูดิโอออกแบบภาษาไทย พาคนเห็นบุคลิกงานแล้วไปดูผลงาน ก่อนอ่านเกี่ยวกับสตูดิโอ ใช้เนื้อหาใน [BRIEF.md](BRIEF.md)

หลักฐานหลัก: [ภาพเดสก์ท็อป FORM / FIELD](images/reference-desktop.png) ขนาดไฟล์ภาพ 1440 × 1719 px เป็นภาพเต็มหน้าจาก viewport 1440 × 1000 ที่เราสร้างเอง ขนาดภาพทั่วไปไม่ยืนยัน CSS viewport; กรณีนี้ทราบจากบันทึกการ capture

[ภาพมือถือของต้นแบบ](images/reference-mobile.png) แจกให้เปิดดูเพิ่มได้ ข้อเสนอมือถือด้านล่างอธิบายการปรับของเว็บภาษาไทย ไม่อ้างว่าถอด behavior จากภาพเดสก์ท็อปได้แน่นอน

## ทิศทางดีไซน์

กระดาษอุ่น ตัวอักษรเกือบดำ แต้มเขียวมะนาว ให้อารมณ์ editorial studio ที่มีระบบแต่ไม่แข็ง จุดจำคือหัวเรื่องใหญ่ฝั่งซ้าย โปสเตอร์เรขาคณิตฝั่งขวา และเส้นคั่นแนวนอนที่จัดจังหวะหน้า ลำดับสายตา: หัวเรื่อง → โปสเตอร์ → CTA → ผลงาน

## เนื้อหาและ assets

ใช้เนื้อหาจาก BRIEF.md รูปโปสเตอร์และแผ่นตัวอักษรสองชิ้นทำด้วย HTML/CSS ไม่มีโลโก้ รูปสินค้า รีวิว หรือตัวเลขธุรกิจภายนอก ชื่อผลงานเป็น concept ไม่ใช่ลูกค้าที่มีอยู่จริง รูปทรงซ้ำจากต้นแบบได้เพราะสร้างและอนุญาต MIT ภายในชุดนี้

## Responsive และ interaction

**เสนอเพิ่มสำหรับเว็บไทย:** ต่ำกว่า 760px ยุบ hero และ about เป็นคอลัมน์เดียว ข้อความก่อนโปสเตอร์ ผลงานเรียงทีละชิ้น เมนูยังแสดงและขึ้นบรรทัดได้แทนซ่อนไว้ ใช้ขอบ 20px หัวเรื่องย่อตามหน้าจอ รักษาวรรณยุกต์และบรรทัดให้ครบ

ลิงก์เลื่อนไปยัง section ที่ระบุจริง details เปิด/ปิดได้ด้วยคีย์บอร์ด ทุกจุดกดอย่างน้อย 44px มี focus ที่มองเห็น เคารพ reduced motion ไม่มีระบบโหลด ส่งแบบฟอร์ม หรือ login

## เกณฑ์ตรวจหลังสร้าง

- ที่ 1440 × 1000: hero สองคอลัมน์ โปสเตอร์ไม่เบียดหัวเรื่อง และสีไม่แย่ง CTA
- ที่ 390 × 844 และกว้าง 320px: ไม่มี horizontal overflow เมนูและข้อความไทยไม่ตัด
- ขยายข้อความเป็น 200%: เนื้อหาอ่านต่อได้และไม่ชนกัน
- Tab เห็น focus; เปิด/ปิดคำถามและลิงก์ไปยัง section ได้
- ใช้ไฟล์ในเครื่องได้ ไม่มีคำขอไปยังฟอนต์ รูป หรือ script ภายนอก

## สิ่งที่ยังไม่ทราบ

ฟอนต์และค่าจริงของเว็บใด ๆ จากภาพอย่างเดียว ยืนยันไม่ได้ ภาพนิ่งไม่บอก hover, focus, animation หรือการส่งฟอร์ม เว็บที่ทำขึ้นมีพฤติกรรมตามข้อเสนอของตัวอย่างนี้ ความคล้ายต้องตัดสินจากภาพที่ render แล้ว และไม่ได้รับรองการทำเหมือนทุกพิกเซล
