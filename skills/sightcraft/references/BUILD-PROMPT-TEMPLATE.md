# BUILD-PROMPT — ชื่อเว็บของผู้ใช้

คัดลอกข้อความด้านล่างพร้อม DESIGN.md และภาพอ้างอิง ไปยัง AI ที่จะสร้างเว็บ

---

สร้างเว็บตาม DESIGN.md ที่แนบ โดยใช้เนื้อหาของฉันและรักษาลำดับสายตา สัดส่วนเลย์เอาต์ และบุคลิกจากภาพอ้างอิง

**เป้าหมาย / กลุ่มผู้ใช้ / เนื้อหาจริง:** กรอกจากโจทย์ผู้ใช้ก่อนส่งพรอมป์ต์ หากยังไม่ทราบให้ถามเฉพาะสิ่งที่จำเป็น

**เทคโนโลยี:** ตรวจโปรเจกต์ก่อน ใช้ stack และองค์ประกอบเดิม ถ้าเป็นเว็บใหม่ที่ยังไม่กำหนด stack ให้ใช้ HTML/CSS และ JavaScript เฉพาะที่จำเป็น

**ขอบเขต:** ระบุส่วนที่จะสร้างจาก DESIGN.md ไม่แก้งานส่วนอื่น

**ลำดับหน้าและ tokens:** ย้ายเฉพาะค่าที่ใช้จริงจาก DESIGN.md มาตรงนี้ รวมสถานะ “ประมาณ” ของฟอนต์ สี และขนาด

**เนื้อหาและ assets:** ระบุรายการที่ผู้ใช้ให้ไว้ รวมไฟล์และข้อความที่ต้องรักษา Placeholder ต้องมองออกว่าเป็นตัวอย่าง

**มือถือและ interaction:** ใช้ข้อเสนอที่ติดป้ายใน DESIGN.md และบอกให้ชัดเมื่อไม่มีหลักฐานจากต้นฉบับ

**Motion:** ย้ายรายการ trigger → effect → duration/easing และ reduced-motion fallback จาก DESIGN.md มาใช้ motion จากภาพนิ่งเป็นข้อเสนอ ใช้ CSS/native platform ก่อนเพิ่ม dependency เนื้อหายังต้องมองเห็นเมื่อ motion หรือ JavaScript ใช้ไม่ได้

**พฤติกรรมที่ต้องทำงาน:** ย้าย behavior contract จาก DESIGN.md ระบุผลของปุ่ม/ลิงก์ ข้อมูลและ state ที่เกี่ยวข้องให้ครบ ถ้าต้องจำข้อมูลให้ทดสอบ reload และกรณีบันทึกไม่ได้ สรุปรายการในเครื่องต้องไม่แสดงว่ามีคำสั่งซื้อหรือชำระเงินจริง

**ตรวจงาน:** เปิดเว็บที่ขนาดเป้าหมาย เทียบกับภาพอ้างอิง ตรวจข้อความยาว การใช้คีย์บอร์ด focus และลิงก์จริง แก้จุดล้นแล้วตรวจซ้ำ รายงานจุดที่ต่างและสิ่งที่ไม่ได้ตรวจ หากเปิดเว็บไม่ได้อย่าอ้างว่าตรวจภาพผ่านแล้ว

ทดลองเส้นทางหลักตั้งแต่ต้นจนถึงผลลัพธ์ ตรวจข้อมูลหลังการกด state ว่าง/ผิดพลาดที่เกี่ยวข้อง และคอนทราสต์ข้อความเล็ก เปิด reduced motion เพื่อยืนยันว่า animation ปิดลงและ controls ยังทำงานได้

ส่งไฟล์เว็บที่เปิดใช้ได้ พร้อมวิธีเปิดและผลตรวจจริง งานนี้จบที่ไฟล์ในเครื่อง เว้นแต่ฉันสั่งเผยแพร่ไว้ด้วย
